# Project Name: Dragon News

## Over view
A simple web application where users can read news, view details.
This project is built using modern web technologies and follows clean UI & UX.

Live Link: https://dragon-news-99.netlify.app/news/0

## 🛠️ Technology Used

- React.js
- Javacript
- React router
- Firebase Auth 
- Tailwind CSS

## Run locally
- Clone the project, git clone https://github.com/jamal-uddin-asif/Dragon-News.git
- Go to project directory, cd yourrepo
- Install dependencies,npm install
- npm run dev
